# PORUCHY · Chceš myš?

Složka obsahuje tři samostatně spustitelné mobilní hry. Každá hra je jeden HTML soubor bez externích knihoven, serveru nebo databáze.

## Spuštění
- Otevři `index.html` ve složce `poruchy` pro výběr her.
- Nebo otevři přímo `tygr.html`, `krokodyl.html` či `netopyr.html`.
- Pro publikování přes GitHub Pages stačí mít zapnuté Pages pro větev `main` a kořen repozitáře.

## Hry a jejich mechanismy

### Tygr
Pět rozhodovacích situací. Hráč rozlišuje vlastní přání postavy od očekávaného scénáře, ověřuje význam přání a respektuje souhlas všech zúčastněných. Skóre je za porozumění záměru a souhlasu.

### Krokodýl
Pět jazykových obrazů převáděných do fyzických mechanismů: čočka, zavlažování, stopa, signál a nové pravidlo spolupráce. Hráč volí funkční doslovný účinek metafory.

### Netopýr
Pět situací založených na změně orientace, denního rytmu a perspektivy. Hráč hledá pravidla, která fungují z pohledu netopýra, a přitom zachovávají vztahy mezi objekty.

## Technické vlastnosti
- HTML, CSS a JavaScript přímo v jednotlivých souborech.
- Ovládání dotykem i myší.
- Bez externích knihoven a síťových požadavků.
- Výsledek je průběžně zobrazován během hry; hra se dá restartovat.
- Hry zatím neukládají dlouhodobé výsledky a neobsahují více hráčů.

## Poznámka k návrhu
Jde o hratelné prototypy. Mechaniky jsou převedené do krátkých rozhodovacích úloh, nikoli o finální výtvarné či zvukové hry. U krokodýla a netopýra jsou pravidla herní interpretací pracovních motivů: doslovný účinek „krokodýlích slz“ a noční/převrácená perspektiva netopýra.
